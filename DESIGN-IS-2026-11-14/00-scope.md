# 旧学前 Lab 官网审查

审查对象是 [正式官网](https://www.jiuxueqian.xin/)在提交 [d035b74](https://github.com/Yann-ar/jiuxueqian-lab/tree/d035b74f72aecdd923565fadc6c602d986797272) 时的首页、三个产品页和 404。主要访客是初次了解三款 App 的读者，以及来找下载、支持和隐私政策的现有用户。优先做好中文阅读和手机操作，沿用正式域名、产品路径、真实截图素材、已经精简过的个人介绍和已核对的外链。

调研并对照了 Landbook 的 [Vogelhaus](https://land-book.com/vogelhaus)、One Page Love 的 [Writebook](https://onepagelove.com/writebook)、[Things](https://culturedcode.com/things/) 和 [Bear](https://bear.app/)。用 GitHub 搜索并阅读了 Anthropic 的 [frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)、Jakub Krehel 的 [better-typography](https://github.com/jakubkrehel/skills/tree/main/skills/better-typography) 和 [better-layout](https://github.com/jakubkrehel/skills/tree/main/skills/better-layout)，同时对照了 [Impeccable](https://github.com/pbakaus/impeccable) 的设计审查范围。选用这些规则指导此次项目，未运行第三方安装脚本。
